# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest combined Chrome + Figma Public Beta Release | Yes |
| Earlier beta versions | No |
| Mixed Chrome and Figma versions | No |

## Report a vulnerability privately

Do not disclose vulnerabilities, credentials, sensitive JSON, private URLs, account information, or exploit details in a public Issue or Discussion.

Report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/SuJiaYi27/UI-Anatomist/security/advisories/new). If that private form is temporarily unavailable, email `sualigaduo@gmail.com`. Include the affected version, affected part, sanitized reproduction, expected and actual behavior, potential impact, and suggested mitigation where safe.

Never include real credentials, cookies, private website content, or another person's data. Use a minimal synthetic reproduction whenever possible.

## Scope

Reports may include secret exposure, unauthorized network requests, unsafe website actions, privacy filter bypasses, malicious JSON handling, dependency or build-chain risks, and ways to abuse a developer-funded API or proxy.

Routine bugs belong in public Issues after all evidence has been sanitized. Confirmed security issues will be assessed privately and disclosed through an appropriate advisory or Release note when a fix is available.
